💻 Visual Studio Code Setup & Pro Suggestions (सुझाव)

Maine aapke liye poora **VS Code Project (`TCMU1_Universal_Controller_VSCode_Project.zip`)** bana diya hai jisme `lib/main.dart`, `pubspec.yaml`, aur `AndroidManifest.xml` taiyar hain. Iske saath aapke system ko aur majboot banane ke liye kuch khaas sujhav (suggestions) niche diye gaye hain:

1. Udhaar / Baki Khata (Pending vs Paid)

Kisan aksar kehte hain "paise baad mein denge". Isliye maine Cash Memo mein **PAID / UDHAAR Toggle** jod diya hai taaki aapko hamesha pata rahe kis customer par kitna rupaya baki hai.

2. Case-Insensitive Substring Matching

Chahe machine `manual start`, `MANUAL START`, ya `Pump Manual Start` bheje — humara parser sabko `.toUpperCase().includes()` se pehchan lega. Chhote-bade aksharon se kabhi galti nahi hogi.

3. Sticky Rate + Manual Override Box

Jo rate aap ek baar daal denge (jaise ₹120/hr), wahi har naye customer ke liye apne aap set rahega. Agar kisi ko fixed ₹100 mein pani dena hai, toh **Manual Total Bill Box** mein seedha 100 likh sakte hain.

4. Native Phone Biometric / PIN (`local_auth`)

Alag se PIN yaad rakhne ki zaroorat nahi! Jo aapke mobile ka Fingerprint ya Screen Lock PIN hai, wahi app aur Settings ko unlock karega.
